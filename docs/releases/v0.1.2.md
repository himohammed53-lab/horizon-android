# Horizon Android 0.1.2

Unofficial Android fork of Horizon (Rust Minecraft 26.3), developed by Muhamed Alzarqi (محمد الزرقي) and Claude.

Based on the Android port of Horizon by Vasysik (https://github.com/Vasysik/horizon-android), which is based on Horizon by Ludovic Marie and the Horizon contributors (https://github.com/ludovic111/horizon, MIT license).

## Changes
- New launcher look: sunset background, glass panels, side menu, Skins page, Settings page.
- Built-in Gravestones and Zoom mods, each with a switch in the launcher Mods list.
- Ely.by and Microsoft accounts, skins over LAN, world import from a ZIP.
- Weak GPU rendering mode, diagnostics report.
- Rendering mode chooser: the last choice is fully visible. Larger touch area for menu buttons.
- The experimental A Good Place animation was removed from this build.

## Horizon Mods
`Horizon_Mods.zip` contains the extra .hmod files made for this fork: Falling Trees, Gamma, Gravestones, Vein Miner and Waypoints. Add them from the launcher Mods page.

## Not verified
Tested by the maintainer on one phone (Realme GT Neo 5 SE). Other devices and Android versions have not been verified.
